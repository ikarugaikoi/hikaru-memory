# LoCoMo memory experiments: consolidated report

[中文](../locomo-2026-11-02.md) · **English** · [日本語](../ja/locomo-2026-11-02.md) · [Home](../../README.en.md)

October 31–November 2, 2026 · Answer model: Claude Opus 5.5 (**medium**) · Main judge: Codex gpt-6.1-sol (**medium**) · Secondary judge: Claude Haiku 5.5 (**low**)

This report consolidates all LoCoMo experiments conducted from October 31 to November 2, 2026. The report ends with a list of local paths to detailed reports and run records.

Each LoCoMo conversation had an isolated test environment with separate memory files and runtime state, preventing information from mixing across conversations. **CA** here means the Conversation Analysis-based review module that extracts conversational cues and stores contextual judgments.

## A known problem with the answering prompts

**All results used the same restriction: do not supplement answers with general knowledge or inference.** This conflicts with LoCoMo's open-domain questions, which require reasoning from conversation and common knowledge.

The problem was discovered after the first run. Rerunning all conditions would be expensive and is not currently planned. The scores below are therefore scores under that restriction. Open-domain performance may be depressed, and differences between conditions may also be affected.

## Conclusion

**Under the original automated scoring criterion, Hikaru's memory-consolidation and retrieval condition B outperformed the full-context baseline F and transcript-retrieval-only A.** Category 1–4 J scores: B 90.27%, F 88.45%, A 86.75%.

The direction survived full rescoring with Haiku and an approximate repeat of B. The magnitude is less certain: the gap is about 2 percentage points, while the judges disagree on about 5% of questions.

Three further findings:

- **F's advantage over A is not robust.** It is 1.70 points under Codex, but 0.59 under Haiku (p = 0.50).
- **CA was barely exercised.** Adding it changed the total by 0.20 points, but answering almost never accessed it, and these questions are poorly suited to evaluating it.
- **B costs substantially more.** About \$376 versus about \$60 each for A and F.

These conclusions apply to these models, prompts, and short conversations, not to every setting where memory competes with full context.

## How memory was used

Answer-time tool logs:

| | Answer batches | Session-start context | Active searches | Of those, expanded scope (`--all`) | Transcript reads by date | Revision-record reads |
|---|---:|---:|---:|---:|---:|---:|
| A | 202 | — | 2387 | — | — | — |
| B | 202 | 202 | 1829 | 8 | 44 | 15 |
| B+CA | 202 | 202 | 1877 | 4 | 54 | 15 |

The tools serve these functions:

- **Session-start context (`mezame`):** load consolidated memories, including current-understanding notes and diary entries. Understanding is organized by person, entity, or event and can be revised; diaries record experiences by date.
- **Active retrieval (`omoide.py`):** search relevant transcript passages. `--all` widens scope to include conversation-review judgments.
- **Transcript reads by date (`fuutou show tm:<date>`):** directly inspect the archived conversation for a given date.
- **Revision reads (`fuutou misekechi`):** inspect how later evidence revised an earlier understanding.

B first loaded consolidated memories in each batch, then searched as needed: 9.1 searches per batch versus A's 11.8, about one-fifth fewer.

## Conversation-review module (CA)

B+CA copied B's 10 consolidated, isolated environments and retained their memories, adding cue extraction, passage reading, and saved review judgments before answering and scoring again. The environments did not configure the literature map/reading interface. Where further checking was needed, the model reread transcripts instead of consulting the accompanying research-analysis materials.

B+CA exceeded B by 0.20 points, with an approximate 95% interval of −0.7 to +1.1. This does not show CA is useless:

- Review judgments are searchable only through expanded scope (`omoide.py --all`). This option appeared 4 times among 1,877 searches; session-start context does not include those judgments.
- In daily use, the association candidate search can find review judgments, but currently logs candidates without putting them into context. The enabled timeline route instead finds earlier experiences by person/entity and supplies only transcript excerpts.
- Conversation review focuses on expression and interactional context; LoCoMo mainly asks factual questions.

Evaluating CA requires testing whether the conversation itself improves.

The practical result here was an approximate rerun: text changed in 759 answers, scores changed on only 3.2%, and the total moved 0.20 points. With only one comparison pair, this is a rough variability estimate.

## Limitations

- **Few repetitions:** A and F ran once; B has one approximate rerun.
- **Daily consolidation rules changed mid-run:** of 272 days, 179 used stop-on-failure, 93 used repair-and-retry.
- **B did not exercise all of Hikaru:** long-term shared-experience records were empty, CA was added later, and per-turn automatic association was not enabled.
- **Reference times differed:** B used the last consolidation execution time; A/F used the end of all conversations.
- **B omitted 8 questions:** their evidence fields were problematic; tables use the 1,978 shared questions.
- **Short conversations:** only around ten to twenty thousand tokens each, allowing F to read everything. Long-running, long-context use remains untested here.
- **No direct comparison with other papers:** models, judges, and call budgets differ.

## Unanswered questions

- Would corrected prompts change A/F/B differences? No near-term rerun is planned.
- Which part of B helps: current-understanding notes, diaries, or something else? This needs ablation.
- How much does memory help when the full transcript no longer fits? This is closer to real use and is not tested by this LoCoMo setup.
- Can CA improve the conversation itself? A different test is needed.
- Would providing transcript evidence to the judge change scores? It could reduce reference-answer errors.
