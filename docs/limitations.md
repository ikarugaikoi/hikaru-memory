# 已知限制与后续改进

**中文** · [English](en/limitations.md) · [日本語](ja/limitations.md) · [首页](../README.md)

Hikaru 已经实现记忆的保存、修订、检索、联想入口过滤和自主活动状态更新。各模块的效果证据不同：合成检查验证具体程序行为，历史对话回放用于观察材料是否有用，两者不能互相替代。本文区分已观察到的结果、尚未解决的问题和下一步验证方向。

## 各模块仍有哪些限制

| 部分 | 当前限制 | 后续改进方向 |
|---|---|---|
| 成团与一般词频 | 常见词组成的共同说法可能被当成普通表达；语言切换也会形成集中分布 | 固定统计口径，在后续日期和不同语言比例上检验；单独观察共同说法的误挡 |
| 对象时间线 | 同一个词不一定指同一个对象；最近一次出现不一定是最有用的一次 | 可考虑基于组合范畴语法（CCG）的句法—语义分析，以及依存类型语义学（DTS）中的照应与预设处理，小规模检验是否有助于核对对象指称及事件角色 |
| 递送与实际用途 | 尚无可靠的方法判断候选记忆对当前对话的实际用途；被递送或提及不等于有用 | 暂无成熟方案 |
| 主动检索 | 能调用工具不等于需要时一定调用；相似度排名也不直接等于用途 | 可考虑组合语义表示与基于类型论的证明搜索，实验性测试谓词—论元、否定及条件等关系能否辅助查询与候选核对；需要时是否主动调用仍是另一项问题 |
| CA 复盘与理解修订 | 程序能检查结构和使用已有判断；语境判断、证据关系和适用范围仍依赖模型 | 考虑实验性结合潜在原因学习与 CA 观察，探索新经历何时应修订既有预期、何时应区分不同情境 |
| 反思与自我强化 | 证据去重防止部分重复计数，但不能自动识别所有错误的支持判断 | 待更多长期运行数据验证，暂无具体改进方案 |
| 压缩与长期保留 | 有保护规则且保留原文，但压缩后能否及时找回重要细节仍需验证 | 待更多长期运行数据验证，暂无具体改进方案 |
| 自主活动 | 兴趣、负担等输入来自模型；默认参数是工程设定，缺少长期效果验证 | 待更多长期运行数据验证，暂无具体改进方案 |
| 安装与集成 | 主要适配 macOS 和特定宿主日志；新机器安装与部分外部服务尚未完整验证 | 暂无 |

对象时间线与主动检索的候选方向包括三个环节：CCG 句法分析与语义组合、DTS 话语语义表示，以及类型检查与证明搜索。对象时间线侧重照应对象及其上下文可及性；主动检索侧重候选材料与查询之间可核对的语义关系。这里列的是可考虑实验的理论方向，尚未确定具体实现。

若开展实验，应保留原文位置，区分明写信息与推测的指称、角色，并与简单规则比较。解析失败、指向不清或没有找到证明时保留未知；形式推理的结果也依赖所选解析，日语小样本的结果不能直接外推到中日混合材料。是否值得采用，需结合效果、误报、耗时与维护成本判断；目前未接入上述两条路径。

## 附录：联想入口测试结果

### 当时测了什么

一次本地探索使用了 30 个有对话的日子的全部已归档对话片段，两位说话者都计入。词级评价只覆盖对象别名中出现至少三次的 305 个：

- 165 个标为具体名字或共同形成的说法；
- 41 个标为纯日常用语；
- 99 个未定，不计入这两类的评价分母。

这里的**别名**来自日常整理时维护的“当前理解”条目：模型把人物、地点、物品或共同经历整理成条目，并填写能指向它们的名字和说法，供联想入口匹配。这里的**评价标签**则是实验时给这些别名另加的分类，用来统计哪些入口被保留或过滤。

下面都是说明分类的合成例子，不是这 305 个别名的实际清单：

- **日常用语**：如“晚安”“我不知道”“ただいま”。它们能出现在许多不同的对话里，单凭再次出现，通常不足以定位某一段共同经历。
- **具体名字**：如某家店的名字“星桥书店”，或在对话里明确指向同一件物品的“银杏书签”。它们提供了可以沿时间线查找的对象线索。
- **共同形成的说法**：如两人说好去书店“就看一眼”，结果待了很久；后来再说“就看一眼”，就会想起那次经历。它可以由普通词组成，辨别时需要看共同使用的语境。

这些类别描述的是表达在这份对话史中的用法。同一句“晚安”如果后来成了某次经历的特定称呼，也可能归入共同说法；仅凭词面拿不准的，保留为未定。分类本身也不保证某一次联想有用。

标签由单一模型标注，初次标注时未看分数；日常用语类别后来收窄过。切片方式、参照样本量和阈值均在同一份材料上探索，没有独立留出集。

候选条件为：出现超过 6 次、一般词频 Zipf ≥ 4.0、按天计算的成团分数 < 0.25 时，不把该别名用作自动联想入口。旧入口过滤还包括高日覆盖率、共享别名和其他别名的结尾；最终回放比较的是在旧规则上增加这条条件。

### 参数选择留下了哪些结果

阶段性汇总保留了以下比较。每格依次是“具体名字或共同说法的保留比例 / 日常用语的阻断比例”，数值为当时报告的四舍五入值：

| 一般词频下限 | 成团上限 | 按天切分 | 按会话片段切分 |
|---|---|---|---|
| 4.0 | 0.15 | 99% / 24% | 99% / 37% |
| 4.0 | 0.25 | 98% / 37% | 99% / 37% |
| 4.0 | 0.35 | 98% / 44% | 97% / 41% |
| 3.5 | 0.25 | 96% / 41% | 97% / 44% |

这些阶段性数字保存在当时的交流汇总中；完整的逐组配置、标签版本和计数表尚未找回，不能直接与最终组合规则的结果合并。按天切分的选择还考虑了具体误挡项，而不是只比较总比例。

其他探索在最终报告中主要留下了以下记录：

| 参数或处理 | 试过的选项 | 留存结论 |
|---|---|---|
| 文档切分 | 每 10、20、40、80、160 个原文片段；按会话片段；按天 | 倾向按天；不同切法会挡掉不同入口 |
| 参照字串长度 | 2～4、2～6、3～8 字 | 报告选择 2～4 字 |
| 参照样本量与种子 | 1,000、3,000、6,000；三个随机种子 | 报告认为 3,000 及以上结果较稳定，未保留各组完整数表 |
| 字种背景校正 | 不校正、按字种校正 | 能减弱部分语言切换效应，也会压低特定话题，因此未作为过滤判据 |
| 低频入口放行 | 最终采用出现 ≤ 6 次时不受新条件阻断 | 尚未找到其他次数门槛的逐组对照，不能称 6 为经过充分搜索的最优值 |

0.25 与 0.35 在后续核对中只改变了四个别名的处理，这四个别名在该次回放里均未触发递送。因此当时选择过滤较少的 0.25；没有依据声称它在一般语料上优于 0.35。

### 词表探索结果

| 指标 | 当时报告值 | 能说明什么 |
|---|---:|---|
| 具体名字或共同说法的保留 | 162 / 165，98.2% | 在所标注的这一类中，大多数入口被保留 |
| 日常用语的阻断 | 15 / 41，36.6% | 日常用语中仍有多数没有被这组条件挡住 |
| 未定别名 | 99 / 305 | 上述比例不覆盖这些歧义项 |

**98.2% 是一类入口的保留比例，不是整体分类准确率，更不是有用记忆的召回率。**

词表统计还有一处待核对的条件命名：旧报告把候选结果称为“叠加规则”，同时给出旧规则保留 161 / 165、新条件保留 162 / 165。固定样本、仅增加排除条件时，保留数不会增加。因此这些数先保留为历史词表探索的报告值，不把它们直接作为现行组合规则的保留率。后续需要固定同一别名集合与配置，分别输出旧规则、新条件单独使用、两者叠加的统计。

### 实际递送回放

同一批历史材料中回放了 1,891 条发言，比较旧入口规则与增加新条件后的组合。这里的“递送”指把一段过去放进模型上下文，不表示模型一定在回答里提到了它。

| 指标 | 旧规则 | 增加新条件后 |
|---|---:|---:|
| 会递送材料的发言 | 100 | 64 |
| 被判有用的递送 | 约 39，旧报告估计值 | 34，64 条全部经过判断 |
| 被判无用的递送 | 约 61，由旧估计推算 | 30，均被标为无用但无害 |
| 递送中的有用比例 | 约 39% | 34 / 64，53.1% |

差分计数为：两边都不递 1,790 条、递同一段 63 条、只在旧规则下递 37 条、只在新组合下递 1 条；合计 1,891。

因此可以说：**这次回放的总递送量减少了 36%；按旧报告估计，无用递送约从 61 降到 30，减少约一半。** 后一个比较的旧基线是估计值，不是两组都完整重标后的精确改善率。

减少递送有代价：旧报告在被移除的 37 条中，判断约 27 条无用、约 4～5 条原本有用，其余没有给出完整分类。新增加的 1 条仍无用。新组合的 64 条中没有标出有害项，但这一结果只覆盖该批材料和这次标注。

### 目前能下的结论

- 成团条件能够减少一部分无用的自动联想，同时会丢掉一些有用入口。
- 它没有解决“相关材料在当前语境下是否有增量用途”，也不负责判断记忆是否真实或值得保留。
- 它只限制自动联想，原文仍保留，主动检索仍可访问；但保留原文不能证明模型会在合适的时候主动查到。
- 阈值、切法和标签来自同一份数据，目前不能外推到其他使用者、其他语言组合或更长时间跨度。

更多公式和当前实现见[决策与记忆中的数学模型](mechanisms.md)。本页只公开汇总数字，不附私人对话、别名清单或逐项分析。
