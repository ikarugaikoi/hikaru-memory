# Biblia：会話を振り返るための文献ガイド

[中文](../biblia.md) · [English](../en/biblia.md) · **日本語** · [トップ](../../README.ja.md)

会話の振り返りは会話分析（CA）を参考にしています。本リポジトリは手がかりの抽出、判断の保存、その後の利用インターフェースを提供します。具体的な分析手順は利用者が設定し、論文本文や私的な分析資料は含めません。

元の運用環境の文献マップから個人情報と個別文献への参照を除き、「どの問題にどの種の研究が参考になるか」だけを残しました。著者、年、題名、引用、文献リンク、私的な注釈、実際の会話例、読書履歴は掲載しません。利用者がテーマごとに文献を選び、ローカルの保存先や参照する章・節を補います。

CA に加えて、隣接する語用論、ポライトネス、言語間の相互行為研究も含みます。研究対象や方法を個別に確認し、すべてを同一の判定規則とみなさないでください。

## 問題に応じて研究分野を選ぶ

| 振り返りの問い | 参考になる文献の種類 | 読む際の注目点 |
|---|---|---|
| 質問、確認、反対、それとも話題を閉じる動きか | 特定の位置で発話がどのような行為として理解されるかの研究 | 前のターンが何を求め、次がどう応じたか。文型と行為の違い |
| 一文だけなら分かるが、会話の流れに合わない | 連鎖組織、隣接応答、挿入・拡張の研究 | 前後を含めた分析単位が必要か。どの未完了の行為に応じているか |
| 何を訂正し、誰が理解の問題に気づいたか | 自己修復、他者開始修復、言語間の修復形式の研究 | 問題が生じた位置、修復の開始方法、誰が修復を完了したか、その後のやり取り |
| 分かったように見えたが1ターン後に誤解が判明した | 次ターンより後で現れる理解の問題と修復の研究 | 後の応答が先の理解をどう捉え直すか。初回の判断と変化の根拠を保つ |
| 音声会話の方法を文字チャットに使いたい | リアルタイムのテキスト対話と音声の修復の比較 | 編集、送信、分割、返信位置の影響。送信済み記録と見えない入力過程の境界 |
| 「嗯」「对」「そう」などの短い応答は何を示すか | 応答詞、聞き手行動、理解の表示、情報の受け取り方の研究 | 出現位置と後続行為。受け取ったことを示しているだけで、賛同とは限らない |
| 話を続け、反対しなければ同意なのか | 評価への賛同・非賛同、応答形式と連鎖位置の研究 | 明示した立場と会話の継続の違い。沈黙やそのまま会話が続いたことだけで、確認が取れたと判断しない |
| 物語には応じたが、感情や立場を受け止めたか | 共感の展開、語りの立場、活動への協調と情緒的な親和の研究 | 語りを進めることと語り手の評価への賛同を分け、それぞれの根拠を見る |
| 出来事への応答がなぜ不適切に見えるか | 物語の連鎖組織、受け手の参加、ターン設計の研究 | 語りの開始・展開・終了。質問、評価、話の続きを促すこと、相手に発言を譲ることのどれが求められるか |
| 悩みの話をさらに聞くか、話題を移すか | 悩みの語りと段階的話題転換の研究 | 隣接応答の中でどう移るか。分析者の好みだけで語り終えたと判断しない |
| 誰が知っているのか。推測をなぜ事実として話したか | 相互行為における知識の分布、知る権利、認識的スタンスの研究 | 直接の経験、伝聞、推論、未確認の情報の違い。断定の強さと根拠の違い |
| 詳しい説明なのに分かりにくい、説教のように感じられる | 母語話者・非母語話者の相互行為、説明方略とその受け止め方の研究 | 相手が実際に示した理解。説明量・表現と受け手が必要とする情報との対応 |
| 面子を傷つけないか。丁寧さを賛同と読んでいないか | フェイスワーク、ポライトネス、関係性の研究 | 関係・場面の影響。丁寧な形だけで承認や内面の感情を証明しない |
| 身体、空間、共有環境の情報が欠けていないか | マルチモーダル相互行為、身体行動、日常実践の研究 | 元の研究で使われた観察資料。テキストだけを根拠に、視線・動作・抑揚を補って解釈しない |

## 振り返りに活用する手順

1. まず原文と前後のターンを読み、何が不確かかを具体化してから研究方向を選びます。
2. 該当する文献を選び、参照できるように設定します。対象、言語、媒体、資料条件を確認し、関連するテーマの文献というだけで、結論の根拠にはしません。
3. 文献で示された区別を手がかりに、元の会話の連鎖を読み直します。後続応答に根拠があれば記録し、足りなければ「分からない」を残せます。
4. 初回の判断と再読を分け、根拠、参照した箇所、判断の変化、不確実な点を記録します。保存した判断は、ツールを通じてスコア計算や内省に反映されます。

キーワード、発話の形、あるいは一度そのまま会話が続いたことだけで、感情・賛同・性格を断定しません。判断の変更には現在の相互行為の根拠が必要で、当てはまりそうな理論が見つかっただけでは不十分です。

## 公開ガイドとローカル設定

利用者とホストモデル向けの文書です。日次整理テンプレートからリンクしていますが、インスタンス内の `biblia` は利用者が管理し、設定スクリプトがこのガイドを取り込んだり既存の読書記録を上書きしたりはしません。

ローカルには「問題 → 選んだ文献 → ファイルまたは正規のアクセス先 → 読む章」を対応させられます。読書ノート、私的な例、分析結果は自分のインスタンスに置きます。完全な分析手順の代わりではなく、CA が各文の唯一の意味を自動判定できるという主張でもありません。
