# 表現の繰り返しを知らせる

[中文](../voice-feedback.md) · [English](../en/voice-feedback.md) · **日本語** · [ホーム](../../README.ja.md)

ある出来事を覚えていても、その呼び名や当時の言葉を毎回繰り返す必要はありません。この任意モジュールは、アシスタントが最近使った表現を集計して伝えます。そのまま言うか、言い換えるか、選択に反映するか、今回は触れないかはモデルが判断します。返答の自動修正や、繰り返しの良し悪しの判定は行いません。

## 三つの通知

| 種類 | 実行時点 | 内容 |
|---|---|---|
| A：開始時の集計 | `mezame` の実行後 | 過去7日間に名前や別名を含んだ返答の数と最終時刻。冒頭・末尾の同じ文や定型表現も別に集計 |
| B：同じ文脈での繰り返し | ユーザーの入力時 | 同じ文脈の直近3時間で繰り返された名前・別名。項目ごとに一度通知し、文脈の圧縮後は再通知可能 |
| C：保護対象の引用 | ユーザーの入力時 | 直前のアシスタント発話に保護対象の原文があった場合の注意書き。発話の UUID で重複を防ぎ、B の回数条件とは独立 |

保護対象は、経験の記録で末尾が `（ねゆき）` または `（いけび）` になっている項目のうち、`「…」` 内にある6字以上の言葉です。記録は残し続けますが、自分から口にする際は今の会話に理由があるかを考えます。完全一致した原文は A/B と口癖の集計から除き、印と C で扱います。連想検索で取り出した一節にも同じ印を添えられます。

## 集計範囲と保存先

対象項目は既存の形式に従います。`### 項目名` の直後に `- 別名: 名前一, 名前二` を置いてください。A は保存済みの発話と、現在の会話の未保存部分を読みます。他の会話でまだ保存されていない発話は含みません。

保存済みの発話にも現在の除外範囲を適用します。現在のログは合言葉と除外時刻を判定してから UUID でまとめ、どれか一つの写しが非公開なら、その発話全体を数えません。不記録区間中や境界を確定できないときは通知しません。

一つの返答に同じ項目の別名が複数あっても一通です。同じ会話の直前のユーザー発話二つに同じ表記がある場合は別集計にします。これは文字列の一致であり、相手の言葉を受けた証明ではありません。それらを除いて二通以上あるときに A/B が通知します。集計窓の前60日間で、返答の5%以上に現れる別名があれば、その項目を A/B から外します。直近7日間の頻度でこの判定を変えることはありません。

口癖は冒頭・末尾から7字以上になるまで文をつなぎ、完全一致を調べます。短い返答、挨拶、保護された引用の断片は除外します。コード内の小さな定型表現リストも使用します。意味の近い言い換えまでは検出しません。

通知済み状態は `.local/state/tomonari/said.json` に3日間保存します。B のキーのハッシュ、C の発話 UUID、通知時刻だけで、本文は入りません。データの置き場所は `HIKARU_DATA_ROOT` に従います。記録中の `ふ` と `Claude` は互換性のための話者ラベルで、表示名とは別です。

## 接続方法

先に[通常の設定](setup.md)を済ませてください。今回の追加は Python のため、この機能だけのために Haskell を再ビルドする必要はありません。既存の設定指紋の確認は引き続き行われます。

1. 必要に応じて [voice-config.example.json](../../templates/voice-config.example.json) を `.local/config/voice.json` にコピーし、`skip_entries` に除外する項目の見出しを入れます。未設定時は `ユーザー（呼び名）` だけを除きます。
2. [hook の雛形](../../templates/hooks.voice.example.json)の絶対パスを変更し、既存設定を残したまま二つの hook を追加します。自動登録や定期実行の設定は行いません。
3. 開始時は `python3 scripts/hikaru mezame` を単独で実行します。`.tools/bin/mezame` と `.tools/bin/hikaru-core mezame` も認識します。`cd ... && ...` やパイプを含む複合コマンドは解析しません。
4. [会話設定の雛形](../../templates/CLAUDE.md)にある表現フィードバックと要約の方針を、自分の指示へ取り入れます。既存の人物設定を丸ごと上書きする必要はありません。

書き込みを伴わない確認用コマンド：

```bash
python3 scripts/hikaru _tomonari_koe --show-after-tool /path/to/authorized-session.jsonl
python3 scripts/hikaru _tomonari_koe --show-prompt /path/to/authorized-session.jsonl
```

この二つは通知済み状態を保存しません。通常の hook はホストから標準入力で JSON を受け取ります。二つの voice hook を外すと A/B/C は停止します。`taguri_hook.py` の保護対象の印は別の接続です。

## 評価と確認

[評価スクリプト](../../scripts/voice_baseline.py)には、自分で固定した集計対象の語句リストを JSON で渡します。[サンプル](../../templates/voice-cues.example.json)は架空の語句です。元の私的な語彙、実測値、実験期間は配布していません。

```bash
python3 scripts/voice_baseline.py --cues .local/config/voice-cues.json --since YYYY-MM-DD --until YYYY-MM-DD
python3 -B tests/voice_feedback.py
```

日付は日本時間の朝5時区切りで、両端を含みます。直前の出現が期間より前にあっても間隔を数えます。語句別の出現回数と重複を除いた返答数を併記し、百通あたりの回数を返答の割合とは区別します。保存位置 `.タイムマシン/.last` が期間の終わりに達していなければ、保存が完了したとは確認できない旨を表示します。ある日のファイルがないだけでは、保存漏れとは判断しません。

macOS の検証は移設した一時環境と合成データ・テスト用の合言葉だけを使い、ネットワークと実際のユーザーディレクトリへの読み取りを禁止します。元実装の17項目と、接続・集計境界など23項目を確認します。Python 用の合成設定指紋を用い、Haskell のビルドや実際の会話ホストの起動は行いません。

集計が正しくても、会話が自然になるとは限りません。通知によって同じ表現がかえって浮かびやすくなる可能性があります。言い換え、常用語・挨拶の除外にも取りこぼしがあり、保存形式の短い会話 ID には既存の衝突の制約が残ります。実際の hook の受け渡しと会話での効果は別に確認してください。繰り返しが数件しかなければ、安定した改善率は判断できません。
