# ローカル公開版の検証

2026年10月31日。macOS arm64、GHC 9.10.3、Python 3.12.12。

## 実施した検証

パスに空白を含む一時ディレクトリにインストール先を作り、テスト用設定と合成会話を使って `hikaru-core`・`hikaru-owntime` を再ビルドしました。バージョンを固定した依存パッケージの既存 package database は読み取り専用で使用しました。コンパイル用サンドボックスはネットワーク禁止で、そのインストールのビルドディレクトリだけに書き込みを許可しました。機能検査もネットワーク禁止で実行しました。

**17項目の検証に合格しました。**

1. 空のインスタンス初期化。
2. 移動先のテスト用インスタンスで両実行ファイルを再ビルド。
3. コア状態の照会。
4. 現在の理解の読み込み。
5. 言語チェックを通した追加と再読み込み。
6. 疑わしい表記がある場合の書き込み拒否と、記録のバイト列が変わらないこと。
7. 記録名のパストラバーサル拒否。
8. 同時変更後の古い草稿の保存拒否。
9. 一時草稿の削除。
10. 合成記録の圧縮計画。
11. 合成 JSONL の保存 dry-run。
12. 合成会話の記録対象となる発話を保存し、合言葉で指定した記録対象外の区間の発話を除外。
13. Python 設定読み込み、合言葉境界、補助モジュールのインポート。
14. 合成原文の字句検索。
15. 埋め込みモデルを起動しないカタログ再構築。
16. モデルを起動しない OwnTime 状態照会。
17. ローカル設定とビルドの不一致を Haskell・Python の両側で拒否。

全 Python ソースの構文解析、ローカル文書リンク、公開ファイル一覧も確認しました。公開ファイルとアーカイブについて、個人情報を含むパス、元の合言葉、アカウント識別子、座標、公開対象外のファイル形式を確認しました。

後から加えた実装説明は現行ソースと照合し、実行コードは変えていません。式やパラメータの説明は、新しい有効性の検証実験を行ったという意味ではありません。文書追加後に一覧、リンク、アーカイブの内容も再確認しました。

## 再現方法

GHC 9.10.3 用のバージョン固定済み依存パッケージを用意してから実行します。

```bash
python3 tests/smoke.py --package-db /path/to/ghc-9.10.3-xxxx/package.db
```

一時コピーにテスト用合言葉を生成してコンパイルし、現在の設定や記憶は変更しません。すでに合成設定を使う開発用ディレクトリでは `python3 tests/smoke.py` でバイナリを再利用できますが、通常は `--package-db` を渡してください。

- 新規マシンでのすべての依存パッケージの導入とモデルのダウンロード。
- BGE-M3 の推論とワーカー。ここでは字句検索とカタログのみを検証。
- 実際の会話や記憶の保存、再読み込み、書き換え。
- 実際の認証情報を使う Claude 自主活動、スマートフォンの位置情報、天気 API へのリクエスト、USB センサー、メディア状態、restic バックアップ。
- 過去のベンチマーク の再実行、全面的な性能比較、ペルソナ評価。

公開用コピーの特定の処理が動くことを確認した記録であり、すべての外部連携が動作確認済みという意味ではありません。これは過去の検証記録であり、翻訳作業でこれらを再実行したという意味でもありません。
