# ローカル公開版の検証

[中文](../validation.md) · [English](../en/validation.md) · **日本語** · [トップ](../../README.ja.md)

2026年10月31日。macOS arm64、GHC 9.10.3、Python 3.12.12。

## 実施した検証

空白を含む一時ディレクトリに新しいインストール先を作り、新規の合成設定と合成会話で `hikaru-core`・`hikaru-owntime` を再ビルドしました。固定依存の既存 package database は読み取り専用で使用しました。コンパイル用サンドボックスはネットワーク禁止で、そのインストールのビルドディレクトリだけに書き込みを許可しました。機能検査もネットワーク禁止で実行しました。

**17項目が通過しました。**

1. 空のインスタンス初期化。
2. 移動先の合成インスタンスで両実行ファイルを再ビルド。
3. コア状態の照会。
4. 現在の理解の読み込み。
5. 言語チェックを通した追加と読戻し。
6. 疑わしい表記の阻止と記録バイトの不変。
7. 記録名のパストラバーサル拒否。
8. 同時変更後の古い草稿の保存拒否。
9. 一時草稿の清掃。
10. 合成記録の圧縮計画。
11. 合成 JSONL の保存 dry-run。
12. 合成の公開発話を保存し、合言葉区間内の合成私的発話を除外。
13. Python 設定読み込み、合言葉境界、補助モジュール import。
14. 合成原文の字面検索。
15. 埋め込みモデルを起動しない目録再構築。
16. モデルを起動しない OwnTime 状態照会。
17. ローカル設定とビルドの不一致を Haskell・Python の両側で拒否。

全 Python ソースの構文解析、ローカル文書リンク、公開ファイル一覧も確認しました。公開ファイルと圧縮物について、私的パス、元の合言葉、アカウント識別子、座標、公開対象外のファイル形式を確認しました。

後から加えた実装説明は現行ソースと照合し、実行コードは変えていません。式やパラメータの説明は、新しい効果実験を行ったという意味ではありません。文書追加後に一覧、リンク、圧縮内容も再確認しました。

## 再現方法

GHC 9.10.3 の固定依存を用意してから実行します。

```bash
python3 tests/smoke.py --package-db /path/to/ghc-9.10.3-xxxx/package.db
```

一時コピーに合成合言葉を生成してコンパイルし、現在の設定や記憶は変更しません。すでに合成設定を使う開発用ディレクトリでは `python3 tests/smoke.py` でバイナリを再利用できますが、通常は `--package-db` を渡してください。
