# 既知の制約と今後の検討事項

[中文](../limitations.md) · [English](../en/limitations.md) · **日本語** · [トップ](../../README.ja.md)

Hikaru には記憶の保存、理解の更新、検索、連想のトリガーの選別、自主活動状態の更新が実装されています。ただし効果の根拠はモジュールごとに異なります。合成データによる検証は特定のプログラム動作を、過去の会話のリプレイは材料の有用性を調べるもので、相互に代用できません。ここでは観察済みの結果、未解決の問題、今後検討できる方向を分けます。

## モジュールごとの制約

| 部分 | 現在の制約 | 今後の方向 |
|---|---|---|
| 集中度と一般的な使用頻度 | よく使われる語を組み合わせた共有表現を、一般的な表現と誤認することがある。言語の切り替えでも集中が生じる | 統計の定義を固定し、以後の記録や、言語の構成比が異なる記録で検証。当事者間の共有表現が誤って除外されるケースを別に調べる |
| 対象の時系列 | 同じ語が同じ対象とは限らず、直近の言及が最も有用とも限らない | 組合せ範疇文法（CCG）の統語・意味解析、依存型意味論（DTS）の照応・前提処理を用いた小規模実験で、指示対象や出来事の役割の照合を助けるか検討可能 |
| 提示と実際の用途 | 候補の記憶が今の会話で役に立つかを信頼できる形で判定する方法は未確立。提示・言及だけでは有用とは言えない | 確立した方法はまだない |
| 能動検索 | ツールを使えることと、必要時に使うことは違う。類似度による順位も用途に直結しない | 合成的意味表現と型理論に基づく証明探索で、クエリと候補の間で、述語と項の対応、否定、条件の関係を照合できるか実験的に検討可能。必要時に自発的に呼ぶかは別問題 |
| CA 振り返りと理解更新 | 構造検査と既存判断の利用はできるが、文脈・証拠関係・適用範囲はモデル依存 | 潜在原因学習と CA の観察を実験的に組み合わせ、新しい経験を既存の予測の更新に使うべき場合と、異なる文脈として区別すべき場合を検討する |
| 内省と自己強化 | 重複排除は一部の二重計上を防ぐが、誤った支持判断すべては識別できない | 長期運用データの蓄積を待って検証。具体的な改善案はまだない |
| 圧縮と長期保持 | 保護規則と原文はあるが、重要な細部を圧縮後に適時取り出せるかは要検証 | 長期運用データの蓄積を待って検証。具体的な改善案はまだない |
| 自主活動 | 関心・負担はモデルの報告で、既定値は実装上の設定。長期効果は未検証 | 長期運用データの蓄積を待って検証。具体的な改善案はまだない |
| 導入と統合 | 主に macOS と特定ログ形式向け。新規マシンや一部外部サービスは未検証 | 現時点ではなし |

時系列と能動検索について検討しているのは、CCG による統語解析・意味合成、DTS による談話意味表現、型検査・証明探索の3段階です。時系列では照応対象と文脈上のアクセス可能性、能動検索ではクエリと候補の検証可能な意味関係を重視します。実験で確かめる候補となる理論であり、実装は未決定です。

実験では原文位置を保持し、明示されている情報と推定した指示対象・役割を分け、単純規則と比較すべきです。解析に失敗した場合、指示対象が不明な場合、証明が見つからない場合には、判断を未確定のまま残します。形式的結果も選んだ解析に依存し、日本語の少数例で得た結果を、中国語と日本語が混在する資料にそのまま一般化することはできません。効果、誤検出、時間、保守コストを見て判断する必要があり、現在この2経路には接続していません。

## 付録：連想のトリガーの実験結果

### 何を測ったか

ある探索的な実験では、会話のある30日分の保存済み区間をすべて用い、両方の話者の発話を対象にしました。語彙単位の評価対象は3回以上現れる対象別名305個です。

- 165個を具体的な名称・共同で形成した表現と分類。
- 41個を純粋な日常表現と分類。
- 99個は未定で、上記2分類の評価分母から除外。

単一モデルがラベルを付け、初回は得点を見ていません。日常表現の範囲は後で狭めています。区切り方、参照標本数、閾値は同じ資料上で探索し、独立したホールドアウトはありません。

候補条件は、出現回数 > 6、一般的な使用頻度を表す Zipf 値 ≥ 4.0、日別集中度 < 0.25 の全条件で自動連想のトリガーから外すというものです。旧規則には多くの日に出現すること、複数項目で共通する別名、他の別名の末尾との一致もあり、最終リプレイでは旧規則に新条件を追加して比較しました。

### パラメータ比較で残っている結果

途中の集計には次の端数を丸めた数値が残っています。各セルは「具体的な名称・共有表現の保持率 / 日常表現の除外率」です。

| 一般的な使用頻度の下限 | 集中度の上限 | 日単位 | セッション区間単位 |
|---|---|---|---|
| 4.0 | 0.15 | 99% / 24% | 99% / 37% |
| 4.0 | 0.25 | 98% / 37% | 99% / 37% |
| 4.0 | 0.35 | 98% / 44% | 97% / 41% |
| 3.5 | 0.25 | 96% / 41% | 97% / 44% |

当時のやり取りの集計に残る値で、各条件の完全な設定、ラベルのバージョン、集計表は見つかっていません。最終的な組合せ規則の結果に直接合算できません。日単位を選んだ理由には、全体の割合だけでなく、具体的に何が誤って落ちたかも含みます。

その他の探索は、主に次の記録が残っています。

| パラメータ・処理 | 試した選択肢 | 残る結論 |
|---|---|---|
| 文書の分割 | 原文10、20、40、80、160区間ごと、セッション区間、日 | 日単位を採用。分割方法によって除外されるトリガーが異なる |
| 参照文字列の長さ | 2〜4、2〜6、3〜8字 | 報告では2〜4字を選択 |
| 標本数とシード | 1,000、3,000、6,000、3つの乱数シード | 3,000以上では比較的安定と報告。全条件の集計表は残っていない |
| 字種背景の補正 | なし、字種ごとの補正 | 一部の言語の切り替え効果を弱めるが特定の話題の集中度も下げるため、選別基準には不採用 |
| 低頻度の別名を除外対象にしない措置 | 最終条件では出現回数 ≤ 6 の別名を除外しない | 他の回数閾値の比較結果は見つかっていない。6を十分探索済みの最適値とは言えない |

後の照合では0.25と0.35で扱いが変わる別名は4個だけで、そのリプレイではいずれも記憶の提示を引き起こしていませんでした。そこで除外の少ない0.25を選びましたが、一般の記録で0.35より優れるという根拠ではありません。

### 別名単位の評価結果

| 指標 | 当時の報告値 | 言えること |
|---|---:|---|
| 具体的な名称・共有表現の保持 | 162 / 165、98.2% | この分類でラベルを付けた入口の大半が残った |
| 日常表現の除外 | 15 / 41、36.6% | この条件でも日常表現の大半は除外されない |
| 未分類の別名 | 99 / 305 | 上記割合は曖昧項目を含まない |

**98.2%は一分類のトリガーの保持率で、全体の分類精度でも有用な記憶の再現率でもありません。**

条件名には未解決の点もあります。旧報告は候補を「既存規則に追加した条件」と呼びながら、旧規則161 / 165、新条件162 / 165の保持数を示しています。固定標本に除外条件を加えるだけなら保持数は増えません。したがって過去の語彙単位の探索の報告値として残し、現行の組合せ規則の保持率とは扱いません。今後は同じ別名集合と設定で、旧規則、新条件のみ、両者の組合せを分けて数える必要があります。

### 実際の提示のリプレイ

同じ過去資料の1,891発話で、旧規則と新条件追加後を比較しました。「提示」は過去の区間をモデルのコンテキストに置くことで、回答で言及したとは限りません。

| 指標 | 旧規則 | 新条件追加後 |
|---|---:|---:|
| 材料を提示する発話 | 100 | 64 |
| 有用と判断された提示 | 約39、旧報告の推定 | 34、64件をすべて判定 |
| 役に立たないと判断された提示 | 約61、旧推定から算出 | 30、すべて役には立たないが悪影響もないと分類 |
| 提示内の有用割合 | 約39% | 34 / 64、53.1% |

差分は、どちらも提示なし1,790件、同じ区間を提示63件、旧規則でのみ提示37件、新規則でのみ提示1件で、合計1,891件です。

**このリプレイでは総提示数が36%減りました。旧報告の推定によれば、役に立たない提示は約61から30へ、およそ半減しています。** 後者は旧規則の推定値に基づく比較であり、両方の結果を全件判定し直して得た厳密な改善率ではありません。

提示を減らすことで失われたものもあります。提示対象から外れた37件のうち、旧報告は約27件を役に立たないもの、約4〜5件を有用だったものとし、残りは完全に分類していません。新たな1件は役に立たないと判断されました。新しい規則の組合せで提示された64件に有害と判定されたものはありませんが、この資料と判定だけに限る結果です。

### 現時点で言えること

- 集中度の条件は一部の役に立たない自動連想を減らす一方、有用な記憶につながるトリガーも除外します。
- その記憶が現在の文脈で何を補えるかの判定は未解決で、真偽や保持する価値も判断しません。
- 自動連想だけを制限し、原文と能動検索は残ります。ただし、保存されていても、必要なタイミングでモデルが自発的に検索するとは限りません。
- 閾値・区切り・ラベルは同じ資料から得たもので、他の利用者、言語構成、長期間への一般化はできません。

式と実装は[数理モデル](mechanisms.md)を参照してください。ここでは集計値だけを公開し、私的会話、別名一覧、個別分析は付けません。
