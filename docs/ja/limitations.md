# 既知の制約と今後の検討事項

[中文](../limitations.md) · [English](../en/limitations.md) · **日本語** · [トップ](../../README.ja.md)

Hikaru には記憶の保存、修訂、検索、連想入口の選別、自主活動状態の更新が実装されています。ただし効果の根拠はモジュールごとに異なります。合成検証は特定のプログラム動作を、過去の会話のリプレイは材料の有用性を調べるもので、相互に代用できません。ここでは観察済みの結果、未解決の問題、今後検討できる方向を分けます。

## モジュールごとの制約

| 部分 | 現在の制約 | 今後の方向 |
|---|---|---|
| 集中度と一般頻度 | 普通の語で作った共有表現を一般表現と誤認しうる。言語切替でも集中が生じる | 統計の定義を固定し、後の日付や異なる言語比率で検証。共有表現の誤った除外を別に見る |
| 対象の時系列 | 同じ語が同じ対象とは限らず、直近の言及が最も有用とも限らない | 組合せ範疇文法（CCG）の統語・意味解析、依存型意味論（DTS）の照応・前提処理を用いた小規模実験で、指示対象や出来事の役割の照合を助けるか検討可能 |
| 提示と実際の用途 | 今の会話で候補記憶が役に立つかの信頼できる判定法は未確立。提示・言及だけでは有用とは言えない | 成熟した方法はまだない |
| 能動検索 | ツールを使えることと、必要時に使うことは違う。類似順位も用途に直結しない | 合成的意味表現と型理論に基づく証明探索で、述語・項、否定、条件関係をクエリや候補照合に使えるか実験的に検討可能。必要時に自発的に呼ぶかは別問題 |
| CA 振り返りと理解修訂 | 構造検査と既存判断の利用はできるが、文脈・証拠関係・適用範囲はモデル依存 | 潜在原因学習と CA の観察を実験的に組み合わせ、新経験で既存の予期を変える場合と別文脈として分ける場合を探ることを検討 |
| 内省と自己強化 | 重複排除は一部の二重計数を防ぐが、誤った支持判断すべては識別できない | 長期運用データの蓄積を待って検証。具体的な改善案はまだない |
| 圧縮と長期保留 | 保護規則と原文はあるが、重要な細部を圧縮後に適時取り出せるかは要検証 | 長期運用データの蓄積を待って検証。具体的な改善案はまだない |
| 自主活動 | 関心・負担はモデルの報告で、既定値は工学的設定。長期効果は未検証 | 長期運用データの蓄積を待って検証。具体的な改善案はまだない |
| 導入と統合 | 主に macOS と特定ログ形式向け。新規マシンや一部外部サービスは未検証 | 現時点ではなし |

時系列と能動検索の候補方向は、CCG による統語解析・意味合成、DTS による談話意味表現、型検査・証明探索の3段階です。時系列では照応対象と文脈上のアクセス可能性、能動検索ではクエリと候補の検証可能な意味関係を重視します。実験を検討できる理論方向であり、実装は未決定です。

実験では原文位置を保持し、明示情報と推定した指示対象・役割を分け、単純規則と比較すべきです。解析失敗、指示不明、証明が見つからない場合は未知を保ちます。形式的結果も選んだ解析に依存し、日本語小標本から中日混合資料に直接一般化はできません。効果、誤検出、時間、保守費用を見て判断する必要があり、現在この2経路には接続していません。

## 付録：連想入口の実験結果

### 何を測ったか

ある探索では、会話のある30日分の保存済み区間をすべて用い、両話者を数えました。語彙単位の評価対象は3回以上現れる対象別名305個です。

- 165個を具体名・共同で形成した表現と分類。
- 41個を純粋な日常表現と分類。
- 99個は未定で、上記2分類の評価分母から除外。

単一モデルがラベルを付け、初回は得点を見ていません。日常表現の範囲は後で狭めています。区切り方、参照標本数、閾値は同じ資料上で探索し、独立したホールドアウトはありません。

候補条件は、出現回数 > 6、一般頻度 Zipf ≥ 4.0、日別集中度 < 0.25 の全条件で自動連想入口から外すというものです。旧規則には高い日被覆率、共有別名、他の別名の末尾もあり、最終リプレイでは旧規則に新条件を追加して比較しました。

### パラメータ比較で残っている結果

途中の集計には次の丸め値が残っています。各セルは「具体名・共有表現の保留率 / 日常表現の阻止率」です。

| 一般頻度の下限 | 集中度の上限 | 日単位 | セッション区間単位 |
|---|---|---|---|
| 4.0 | 0.15 | 99% / 24% | 99% / 37% |
| 4.0 | 0.25 | 98% / 37% | 99% / 37% |
| 4.0 | 0.35 | 98% / 44% | 97% / 41% |
| 3.5 | 0.25 | 96% / 41% | 97% / 44% |

当時のやり取りの集計に残る値で、各条件の完全な設定、ラベル版、計数表は未回収です。最終的な組合せ規則の結果に直接合算できません。日単位を選んだ理由には、総割合だけでなく、具体的に何が誤って落ちたかも含みます。

その他の探索は、主に次の記録が残っています。

| パラメータ・処理 | 試した選択肢 | 残る結論 |
|---|---|---|
| 文書の分割 | 原文10、20、40、80、160区間ごと、セッション区間、日 | 日単位を選好。切り方で落ちる入口が違う |
| 参照文字列の長さ | 2〜4、2〜6、3〜8字 | 報告では2〜4字を選択 |
| 標本数とシード | 1,000、3,000、6,000、3つの乱数シード | 3,000以上では比較的安定と報告。全数表は残っていない |
| 字種背景の補正 | なし、字種ごとの補正 | 一部の言語切替効果を弱めるが特定話題も下げるため、選別基準には不採用 |
| 低頻度入口の免除 | 最終条件は出現 ≤ 6 を免除 | 他の回数閾値の比較は未発見。6を十分探索済みの最適値とは言えない |

後の照合では0.25と0.35で扱いが変わる別名は4個だけで、そのリプレイではいずれも提示を発生させていませんでした。そこで除外の少ない0.25を選びましたが、一般の記録で0.35より優れるという根拠ではありません。

### 語彙探索の結果

| 指標 | 当時の報告値 | 言えること |
|---|---:|---|
| 具体名・共有表現の保留 | 162 / 165、98.2% | この分類でラベルを付けた入口の大半が残った |
| 日常表現の阻止 | 15 / 41、36.6% | この条件でも日常表現の大半は止まらない |
| 未定別名 | 99 / 305 | 上記割合は曖昧項目を含まない |

**98.2%は一分類の入口保留率で、全体の分類精度でも有用記憶の再現率でもありません。**

条件名には未解決の点もあります。旧報告は候補を「重ねた規則」と呼びながら、旧規則161 / 165、新条件162 / 165の保留数を示しています。固定標本に除外条件を加えるだけなら保留数は増えません。したがって歴史的な語彙探索の報告値として残し、現行の組合せ規則の保留率とは扱いません。今後は同じ別名集合と設定で、旧規則、新条件のみ、両者の組合せを分けて数える必要があります。

### 実際の提示のリプレイ

同じ過去資料の1,891発話で、旧規則と新条件追加後を比較しました。「提示」は過去の区間をモデルのコンテキストに置くことで、回答で言及したとは限りません。

| 指標 | 旧規則 | 新条件追加後 |
|---|---:|---:|
| 材料を提示する発話 | 100 | 64 |
| 有用と判断された提示 | 約39、旧報告の推定 | 34、64件をすべて判定 |
| 無用と判断された提示 | 約61、旧推定から算出 | 30、すべて無用だが無害と分類 |
| 提示内の有用割合 | 約39% | 34 / 64、53.1% |

差分は、双方提示なし1,790件、同じ区間を提示63件、旧だけ提示37件、新だけ提示1件で、合計1,891件です。

**このリプレイでは総提示数が36%減りました。旧報告の推定によれば、無用な提示は約61から30へ、およそ半減しています。** 後者の旧基準は推定で、両群を全件再ラベルした精密な改善率ではありません。

減らす代償もあります。削除した37件のうち、旧報告は約27件を無用、約4〜5件を元は有用とし、残りは完全に分類していません。新たな1件は無用でした。新組合せの64件に有害のラベルはありませんが、この資料と判定だけに限る結果です。

### 現時点で言えること

- 集中度の条件は一部の無用な自動連想を減らす一方、有用な入口も落とします。
- 現在の文脈で追加の用途があるかは未解決で、真偽や保留価値も判断しません。
- 自動連想だけを制限し、原文と能動検索は残ります。ただし保存されていることは、適時に自発検索する証明ではありません。
- 閾値・区切り・ラベルは同じ資料から得たもので、他の利用者、言語構成、長期間への一般化はできません。

式と実装は[数理モデル](mechanisms.md)を参照してください。ここでは集計値だけを公開し、私的会話、別名一覧、個別分析は付けません。
