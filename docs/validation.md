## 如何复现

先在本机准备 GHC 9.10.3 的锁定依赖，再运行：

```bash
python3 tests/smoke.py --package-db /path/to/ghc-9.10.3-xxxx/package.db
```

该入口在临时副本中生成合成口令并编译，不修改当前实例的配置和记忆。已有合成配置的开发目录可复用其二进制运行 `python3 tests/smoke.py`；普通用户应传入 `--package-db`。
