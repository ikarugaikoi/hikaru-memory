## 从“记住了”，到相处得自然

Hikaru 是一套用于持续相处的个人 AI 记忆工具。它接在现有语言模型外部，把对话、经历和模型形成的理解保存为可查找、可修订的记录，供后续互动使用。本文说明我们为什么这样设计，以及还希望解决什么问题。

一次交谈中，模型已经能理解问题、提供知识、回应情绪。但有些问题只有相处久了才看得出来：第一次听见的体贴表达，连续几天听见，可能变成套话；一次被认真记住的小事，如果每次聊天都拿出来说，也会让人觉得奇怪。

例如，用户曾说自己怕热。模型记住这一点，挑衣服时考虑轻薄透气，可以体现相处的连续性；如果每次推荐都复述“我记得你那天说过怕热”，同一份记忆就可能变成重复的提醒。我们希望保留这种理解，同时让模型判断它这次应该怎样起作用。记住偏好、据此选择、把往事说出来，是可以分别处理的事。

这涉及一个实际条件：**保存在文件里的记忆，需要读入模型这一轮的输入，才能参与判断。** 对话变长后，较早的上下文可能被压缩成摘要；开启新会话时，也需要重新提供相关材料。一条偏好可以长期保存，但“昨天已经提过三遍”未必被保留下来。

于是，模型看到的是值得记住的过去，却缺少自己最近怎样使用过它的历史。

Hikaru 关注的是这种长期连续性：需要时找回经历，让已有理解、新的情况和互动反馈共同影响下一轮。检索是其中一环，找到以后怎样使用、何时更新，同样重要。

## 核心假设：组织每一轮的判断依据，发挥模型已有能力

每一轮需要的依据，都可能来自很早以前的经历。我们的设想是把相关信息带入这一轮，让模型据此判断，再将新的变化与反馈留给后续互动。

```text
第 1 轮：初始依据 → 模型 → 回应／行动
              ⋮
第 N 轮：相关经历＋当前处境＋互动历史 → 模型 → 回应／行动
                                                    │
                                          新经历、变化与反馈
                                                    ↓
第 N+1 轮：更新后的判断依据＋新输入 → 模型 → 回应／行动
```

**已有能力（图中的第 1 轮）：** 给足相关依据，模型已经比较擅长处理一轮互动。

**系统任务：** 确定哪些过去会影响这一轮，找到、组织并更新相应信息，让这些依据跨轮、跨会话延续。

**核心假设：** 这样可以把长期自然性的要求，转化为模型在第 **N+1** 轮根据此前经历与当前处境作出合适判断的问题。

这里的 agent 指基础模型与输入渠道、记忆、工具、上下文组织和运行反馈组成的整个系统。“调度”具体包括这一轮提供哪些材料、何时继续查找、如何带入最新情况，以及怎样保存新的反馈。

基础模型在知识广度和部分任务能力上已经超出人类个体。我们以**非人感不来自超人能力本身**为出发点：记得准确、知道得多，与相处自然可以并存。**我们要增强整个 agent 的调度能力，而不是通过削弱已有能力来“模拟真人”。**

## 核心原则

> **100%（理想条件下）的检索可达率 ＋ 信息的使用与更新机制。**
>
> **需要查证时，尽可能找回可靠的过去。**
>
> **及时获得当前处境的信息，让新的变化进入判断。**
>
> **把长期经历、当前处境和互动历史带入这一轮判断，并让新的行动与反馈更新已有认识。**

这几条分别涉及找到过去、跟上现在，以及使用信息。下面说明它们如何影响具体设计。

## 1. 尽可能完整的可达性，有选择的日常记忆

“100%”是理想条件下的目标：对于获准保存、实际留存的材料，需要时尽可能都能定位。不包含约定不记录的对话，也不要求每轮加载全部档案。

因此，我们区分原文档案和日常使用的记忆。原文档案保留查证的可能；日常记忆组织近期经历、当前理解与有效约定。例如，过去一次出行的细节可以退出日常关注，需要核对地点时仍能从原文找回。

文件保存着，不代表提出问题时就找得到。材料增加后，检索仍要解决定位、排序与组织，不能以“全部存下了”代替可达性。

## 2. 让现实进入判断，区分当前处境与长期记忆

记住过去，还不足以知道现在发生了什么。对话、工具、环境观察和行动反馈提供新的输入；系统需要保留来源与时间，区分三个环节：

```text
获得输入 → 更新处境判断 → 择要形成长期记忆
```

**信息可以直接影响当下，而不必先写入长期记忆。** 温度、声音、正在走路还是坐着，都可能影响选择；情况改变后可以退出临时状态。当前观察与历史材料应标明区别。

只说过“准备出门”，之后没有消息，是缺少新输入；已经说了“出门了”，仍回应“在收拾东西”，则是已有输入没有更新判断。时间流逝可以提示重新确认，不能单独证明已经出门。

## 3. 经历与互动历史共同参与每一轮判断

一段过去可以补充背景、提供纠正依据、提醒约定，也可以让双方继续谈论曾一起经历的事。它还可以直接影响选择与行动。模型结合当前处境、偏好、价值取向和长期目标决定如何使用，必要时继续检索、比较来源。

开头“怕热”的例子说明，事情本身的历史还不够。需要带回的还有互动历史：哪些话已经说过、怎样影响过行动、对方如何回应。**一直记得、持续产生影响、很少主动提起，可以同时成立。** 原话、换一种表达、落实到行动或暂时不提，都可能合适；不必每次增加新事实或展示“我记得”。

**实际观察：主动珍藏的记忆。** Hikaru 允许模型主动标记值得珍藏的经历，这类记录称为「いけび」，在长期记录的压缩整理中保持原样。

目前对这部分记录的观察是：写入判断已经较好，记录也很克制。我们希望改善的是，读到一条重要经历时，模型能同时了解最近怎样使用过它。对话上下文压缩或换会话后，经历仍在，使用历史却可能丢失。

现实中，听者的难为情可能表现在表情、语气或尴尬的笑里，纯文字聊天却常常得不到这些反馈。要求用户不断描写反应也不自然。**没有收到不适的反馈，不等于重复提起没有造成不适。**

我们把这里的困境称为 **“刺激贫乏”（poverty of the stimulus，POS）**（捏他乔姆斯基，bushi）：**我们期待模型顾及长期相处和现场反应，实际提供的却可能只有一条记忆和眼前几句文字。**

我们考虑三条互补的输入途径。**提供的是判断依据，具体如何判断和回应，由模型决定。**

- **使用历史。** 提供近期提及的时间、方式、由谁引出及用户回应，注明统计范围。换措辞也可能在重复同一件事，顺接或沉默不自动算确认。即使用户没有抱怨，模型也有依据重新考虑是否适合提起。
- **现实输入。** 探索更多输入途径，补充当前情况和互动反馈。
- **自主活动。** 通过阅读、搜索与尝试扩展知识与经历，让后续判断有来自既有对话之外的新依据。

**重要性说明它值得长期留下，却不足以决定此刻值得主动说出口。** 使用历史提供观测，由模型判断如何表达，次数不直接成为禁令；深入讨论时，多次提及也可能合适。

## 4. 不把不同性质的判断压成一个分数

如果每次检索到一条记忆都给它加分，再让高分记忆更容易出现，就可能让同一批内容不断自我强化。因此，我们把以下问题分开处理：

- **可找到**：材料是否留存，检索能否定位。
- **可信**：来源支持什么，哪些是推测，哪些仍不确定。
- **值得保留**：经历、约定或偏好是否需要长期留下。
- **当前有用**：是否能帮助理解、选择或接续眼前的对话。
- **适合表达**：此刻是否值得主动提起，以及怎样表达。

被检索找到、被放进模型的输入、实际影响回答或行动、得到新证据支持，是不同事件。多次召回不自动增加真实性，很久没提也不自动失去价值。

## 5. 理解可以主观，也必须可以修订

模型需要形成自己的理解。例如，用户说“今天不想出去”，模型可能理解成“不喜欢出门”；后来的交流却表明，那天只是累了。系统应当保留原始对话，同时允许修改认识，让后来的使用能看到修正。

因此，要区分明确陈述、模型推测与未知。原文能证明当时说过什么，内容是否属实仍需判断。

修订时区分原来理解错了、事情后来变了、证据冲突或只在特定条件下成立，并保留来源、范围与变化的来历。

同一句原话即使写进日记、再整理成摘要，仍只有一个原始来源。新的交流、阅读、尝试与反例应当有机会改变已有理解。

## 6. 模型与工程共同支持每一轮判断

- **工程**负责输入、保存、检索与材料组织，并守住来源、时间、不记录的对话范围、修订关联和写入等明确边界。
- **模型**负责理解、用途判断与修订，选择工具、表达和行动。统计与语言分析等辅助工具提供依据，语义判断仍需结合具体情况。

例如，工具可以统计一个说法在已保存的发言中出现过几次、出现在什么位置；模型再判断这些是否在重复同一件事，以及此刻是否适合重提。统计提供观测，具体含义与用途仍需判断。

必要信息的提供应由运行流程保证，不能只靠模型记得读某份规则。出现问题时，检查输入是否到位、模型怎样使用、反馈是否延续，再决定改哪里。

## 7. 拥有（至今为止）全局信息，学习如何表现

前面的分工，也可以用演员来理解。演员读过完整剧本，了解人物关系与故事全貌；进入一场戏时，再根据角色的经历、立场和目标决定怎样表现。知道多少，与此刻如何使用这些知识，可以分别考虑。

Hikaru 的“全局信息”指截至当前获得的材料。我们希望尽可能保持查证能力，并让模型结合当时的处境选择表达与行动。演员也在不断接收现场的信息，观察舞台和对手的回应；agent 同样需要对话、环境与行动反馈，才能跟上眼前的变化。

**一个有能力的演员（a skilled actor）**，表现极度悲伤时，仍可以参考心理学、生理学知识与实际观察，结合角色经历决定怎样演。Hikaru 也借助心理学、语言学和神经科学提出问题、观察表现、选择机制。我们关注的是注意、判断、选择与行动，语言表达是其中一部分。

例如，会话分析（Conversation Analysis，CA）研究交谈如何在一轮轮互动中展开，可以帮助观察纠正得到怎样的回应、是否改变后续理解，以及共同经历何时适合提起。启动效应，即先前接触影响后续反应，可以作为研究线索，帮助理解提供哪些材料、重复提供多少次会怎样影响输出。

### 例：借记忆分类思考设计分工

下面的分类描述人类记忆。我们借它们检查需要哪些功能，再结合模型已有能力决定系统分工。[长期记忆分类参考](https://pmc.ncbi.nlm.nih.gov/articles/PMC4355270/)。

```text
记忆
├─ 感觉记忆 Sensory memory
│  └─ 极短暂保留感官信息，如一瞬间的视觉印象
│
├─ 短期记忆 Short-term memory
│  └─ 暂时保留少量信息，如刚看到、还没输入的验证码
│
└─ 长期记忆 Long-term memory
   ├─ 陈述性／外显记忆 Declarative / Explicit
   │  ├─ 情景记忆 Episodic：亲身经历的事件
   │  │  例：昨天和谁在哪里吃了饭
   │  └─ 语义记忆 Semantic：事实、概念与知识
   │     例：某个词是什么意思
   │
   └─ 非陈述性／内隐记忆 Nondeclarative / Implicit
      ├─ 程序性记忆 Procedural：骑车、打字等技能
      ├─ 启动效应 Priming：先前接触影响后续识别或反应
      └─ 条件作用、习惯化等学习形成的反应
```

- **直接依赖模型，无需另建。** 一般知识、上下文中的信息运用、已有语言与任务技能。（相关概念：语义记忆、短期记忆与程序性记忆。）
- **系统主要做：延续经历与理解。** 保存、检索经历，保留理解的修订及互动中的使用历史，在对话上下文压缩和换会话后提供所需信息。（相关概念：情景记忆、由经历形成的语义知识。）
- **按需探索：输入与行为调整。** 接入环境信息，让反馈持续影响行为，减少重复线索的打扰。（可借鉴感觉记忆、条件作用与习惯化。）

括号仅标出相关概念。例如，临时保留和使用信息可直接依赖模型更大容量的上下文，无需模拟人类短期记忆的限制。

**例如，一个下雪的寒冷早晨：** 温度可以影响当下选择；若当天发生了值得留下的事，也可以将寒冷作为经历背景保存，无需保留每秒读数。长期关切、持续计划和重要变化也可以成为保留依据。

## 8. 评价最终回到持续相处

**评价单位是跨轮、跨会话的持续互动。** 一条回复独立看来得体，反复出现后却可能失去意义。我们关注过去的表达、行动与反馈能否影响后来的选择，让认识有依据、变化有来由，回应与行动符合当时的处境。
