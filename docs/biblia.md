# Biblia：对话复盘的文献导航

对话复盘的设计参考会话分析（CA）。本仓库提供线索提取、判断存储及后续使用接口；具体分析规程需由使用者配置，不附带论文原文与私人分析材料。

这份导航由原部署的文献地图脱敏、去引用化整理而来，只保留“遇到什么问题，可以参考哪类研究”。不列具体作者、年份、篇名、引文或文献链接，也不包含私人批注、真实对话案例和阅读历史。使用者可以按这些主题自行选择文献，并补充本地路径与阅读位置。

导航涉及 CA，也包括与它相邻的语用、礼貌及跨语言互动研究。不同研究的对象和方法需要分别确认，不能把它们当成同一套判定规则。

## 按问题找研究方向

| 复盘时的问题 | 可以参考什么样的文献 | 阅读时重点留意 |
|---|---|---|
| 这句话是在提问、确认、反对，还是准备结束话题？ | 研究话语如何在具体位置被理解为某种行动的文献 | 前一轮给出了什么条件，下一轮如何回应；字面句式与实际行动的区别 |
| 单看一句话能懂，放回对话却接不上 | 研究会话序列、相邻回应、插入与扩展的文献 | 分析单位是否需要扩大到前后几轮；当前回应接的是哪一个尚未完成的行动 |
| 对方是在纠正什么？是谁先发现理解出了问题？ | 研究自我修复、他人发起修复及跨语言修复形式的文献 | 问题出现的位置、修复的发起方式、由谁完成，以及后续是否接续成功 |
| 当时似乎听懂了，隔了一轮才发现理解错了 | 研究下一轮之后才显现的理解问题与修复的文献 | 较晚出现的回应怎样重新解释前面的理解；保留先前判断及其变化依据 |
| 想把口语会话的分析方法用到文字聊天 | 比较即时文字互动与口语修复的文献 | 编辑、发送、分条和回复位置的影响；已发送记录与不可见的输入过程之间的边界 |
| “嗯”“对”“そう”等短回应到底表达了什么？ | 研究应答词、听者行为、理解展示与信息接收的文献 | 短回应出现的位置、后续行动，以及它是否仅表示收到，而非赞同 |
| 对方顺着聊、没有反对，是否就算同意？ | 研究评价中的赞同与不赞同、回应形式和序列位置的文献 | 明确表达的立场与对话继续进行之间的区别；不能仅凭沉默或顺接补出确认 |
| 回应了叙事，却不确定有没有接住情绪与立场 | 研究共感的展开、叙事中的立场、活动配合与情感亲和的文献 | 是帮助故事继续，还是认同叙述者的评价；不同层面的回应分别有什么依据 |
| 对方讲了一件事，回应为什么显得不合适？ | 研究讲故事的序列组织、受话者参与和话轮设计的文献 | 叙事如何开始、展开与结束；当前需要的是追问、评价、接续还是暂时让出话轮 |
| 谈烦恼时，何时继续追问、何时转向别的话题？ | 研究烦恼叙述及逐步话题转换的文献 | 转换如何在相邻回应中发生；不要仅凭分析者的偏好认定对方已经说完 |
| 谁知道这件事？一个推测为何被说成了确定事实？ | 研究互动中的知识位置、知情权与认识立场的文献 | 亲历、转述、推断及未知的来源差异；说得肯定与实际有依据的区别 |
| 解释很完整，对方却觉得难懂或被说教 | 研究母语者与非母语者互动、解释策略及解释接受情况的文献 | 对方实际展示了怎样的理解；说明的多少、表达方式和受话者需求如何配合 |
| 担心一句话伤面子，或把礼貌理解成了赞同 | 研究面子工作、礼貌与互动关系的文献 | 关系和场景如何影响表达；礼貌形式不能直接证明认可或内在情绪 |
| 怀疑文字里缺了身体、空间或共同环境的信息 | 研究多模态互动、身体行动及日常实践的文献 | 原研究用了哪些可观察材料；只有文字时，不能补造视线、动作或语调 |

## 怎样接入复盘

1. 先读原文及前后话轮，写清楚具体哪里拿不准，再按问题选择研究方向。
2. 自行配置对应文献。查阅时确认研究对象、语言、媒介和材料条件；导航中的主题不是现成结论。
3. 将文献提供的区分带回原序列核对。后续回应能提供依据时就记录；没有足够依据时可以保留“不知道”。
4. 初判与再读分开保存，记录依据、阅读位置、判断改变了什么及哪里仍不确定。已经形成的判断再由工具接入评分或反思。

不要把机械关键词、某种话语形式或一次顺接直接当成情绪、赞同或人物性格。判断改变应有当前互动的依据，而不只是因为找到了一段看似适用的理论。

## 公开导航与本地配置

本文件供使用者和宿主模型查阅。每日整理模板链接到这里；实例中的 `biblia` 仍由使用者维护，配置脚本不会把这份导航自动写入或覆盖已有读书记录。

本地可以建立“问题主题 → 自选文献 → 文件位置或合法访问链接 → 待读章节”的对应关系。实际阅读笔记、私人例子及分析结果留在自己的实例中。导航不代替完整分析规程，也不意味着 CA 能自动判断一句话的唯一含义。
