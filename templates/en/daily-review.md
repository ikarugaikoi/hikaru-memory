# Daily review template (does not install a scheduled job)

1. Read tool usage before `ochibo`. Ensure the log directory contains only authorized projects.
2. Collect archivable conversations. Check status and do not rewrite excluded intervals into other records.
3. `shirushi` produces cue candidates, not emotional or conversational conclusions. Use original and neighboring turns as evidence. When unsure, consult the [Biblia map](../../docs/en/biblia.md), then literature you have configured; record evidence and uncertainty.
4. Write actual responses, corrections, and uncertainties into conversation review, then form the daily summary.
5. Revisions to current understanding must retain source, scope, reason, and the location of the old understanding. Repetition alone does not increase truth.
6. `fuutou fade` supplies a compression plan. Understand its scope and protections before consolidating. The command does not generate summaries.
7. Put unfinished matters in pending records. Check new rules for duplication. If nothing merits a record, writing is optional.

Adapt this procedure to your formats and model, then configure scheduling yourself. When copying into `.local/daily-review.md`, change the Biblia link to `../docs/en/biblia.md` so it resolves from that location.
